# Birthday photo puzzle for Vova

Статический desktop-only мини-сайт. Сервер, база, API и домен не нужны.

## Что внутри

- `index.html` — страница сайта
- `styles.css` — дизайн
- `app.js` — контент, пазл и переходы между фреймами
- `assets/photos/` — фотографии
- `assets/visuals/` — логотипы и дополнительные визуалы

## Как проверить локально

Самый простой вариант — открыть `index.html` двойным кликом. Если браузер ограничит локальную загрузку ресурсов, запусти в папке проекта:

```bash
python3 -m http.server 8000
```

После этого открой `http://localhost:8000`.

## Как выложить на GitHub Pages

1. Создай новый репозиторий в личном GitHub, например `vova-birthday-puzzle`.
2. Загрузи **всё содержимое этой папки** в корень репозитория.
3. Открой `Settings` → `Pages`.
4. В `Build and deployment` выбери `Deploy from a branch`.
5. Branch: `main`, folder: `/ (root)` → `Save`.
6. Через 1–3 минуты GitHub покажет ссылку вида `https://USERNAME.github.io/vova-birthday-puzzle/`.

## Как заменить текст Фрейма 8

Открой `app.js` и найди объект с `id: 8`. Замени:

```js
{ text: '«здесь будет текст от Игоря и Ярика»', author: 'Игорь и Ярик' }
```

на финальный текст. Остальную механику менять не нужно.

## Как заменить фотографию

Замени нужный файл в `assets/photos/`, сохранив имя (`frame-1.webp`, `frame-2.webp` и т. д.).

Для текущей механики:
- Фреймы 1–6 подготовлены как портретные 3:4.
- Фреймы 7–8 — горизонтальные 4:3.

## Ограничения текущей версии

- Только desktop: минимальный экран 1120 × 680.
- Пазл состоит из 12 квадратов.
- Кусок фиксируется только в правильной клетке.
- Мобильная версия намеренно не делалась.
